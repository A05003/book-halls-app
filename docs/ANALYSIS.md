## مستودعات ومنتجات الحجز

- [BookSpace](https://github.com/rishi-raj-jain/BookSpace): حجز مساحات بـ Next.js وRedis برخصة SSPL. لا يوفر منطق تعارض الحجوزات ولا محاسبة، ولا يصلح أساساً لنا.
- [وحدة Hall Booking System لـ Odoo](https://apps.odoo.com/apps/modules/13.0/hall_booking_system): دورة حالات (طلب، مؤكد، مكتمل، ملغي)، تقويم، وإيصال تأكيد. طُبقت الدورة والتقويم.
- [BookBanquetRoom](https://www.getapp.com/all-software/a/bookbanquetroom-com/) (تجاري): جدول دفعات مع تتبع الاستحقاق وكشف تعارض الحجز. طُبق جدول الدفعات والتنبيه بالتأخر.
- لم نجد مستودعاً مفتوح المصدر لقاعات الأفراح يجمع الحجز والمحاسبة والكيانين، فهذا ما سيميز نظامنا.

## تحسينات النسخة الثانية (من التحليل)

1. دورة حياة الحجز: مبدئي، مؤكد (بعد العربون ٣٠٪)، مكتمل (بعد السداد الكامل)، ملغي.
2. جدول دفعات لكل عقد (٣٠٪ / ٤٠٪ / ٣٠٪) وتنبيهات التأخر في لوحة المدير.
3. الكيان بُعد محاسبي على كل قيد، مع أرباح وخسائر لكل كيان وميزان مراجعة.
4. الإلغاء بقيد عكسي للعقود والسندات، وسلسلة تجزئة تكشف أي تلاعب بالقيود.
5. إقفال الفترة، وأدوار (مدير، محاسب، استقبال) بصلاحيات مختلفة.
6. تقويم شهري حقيقي، وكشف حساب لكل عميل.

## ما لا يزال تجريبياً

التجزئة (FNV) للعرض فقط وستُستبدل بـ SHA-256 على الخادم. لا توجد قاعدة بيانات ولا تسجيل دخول ولا PDF حقيقي بعد.
